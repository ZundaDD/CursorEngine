# CursorEngine
### 介绍

CursorEngine提供基于规则的个性化光标样式管理，并在带社区网络的版本中提供类似创意工坊的功能。

### 环境依赖

软件依赖于.NET Runtime框架，可于[此处](https://dotnet.microsoft.com/zh-cn/download)安装。

### 软件获取

软件发布版本位于[Releases · ZundaDD/CursorEngine](https://github.com/ZundaDD/CursorEngine/releases)，其中以o结尾的版本表示带社区网络的版本，不以o结尾的版本表示单机版本。所有发布的软件都是开箱即用，无需再安装依赖和注册表登记。
